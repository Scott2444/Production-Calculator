# Alias

An alias project allows the reuse of another project's components.

## What is Alias

An aliased project will use the components of another project, so you can immediately start a workflow without having to spend time entering the same game data.

## Why Use Alias

- You save time by not copying game data into the Production Calculator
- The original project owner will (hopefully) update their project

## Miscellaneous

Aliased projects cannot be public.

## Practical Guidance

- Use aliasing when your game is popular and others have already created a project
- Use a standard project when you want full independent ownership

## Future Features

If the original project owner deletes their project, all referenced projects become invalid. This will be changed.

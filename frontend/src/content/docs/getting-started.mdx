# Getting Started

This page is a practical starting point for adding your first project and workflow.

## 1. Create Or Select A Project

- Open your user route in the app
- Create a new project from the project controls
- Optionally set visibility and description

## 2. Add Core Components

At minimum, add these project resources:

- Products
- Recipes
- Machines

Attributes are optional but recommended when you want to track extra metrics such as power, pollution, or cost.

## 3. Build A Workflow

- Create a workflow in the selected project
- Set one or more target products and rates
- Let the chart solve demand
- Enter supply data (actual machine counts and related settings)

## 4. Iterate

Use preferred recipe selection, external product toggles, and component edits to refine the plan.

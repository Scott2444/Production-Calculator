# Process Nodes

Process nodes represent recipe execution units in the workflow chart.

## Fields

- Recipe
- Machine
- Modifier (optional)
- Calculated machine count and rate
- Actual machine count and rate

## Role In The Graph

A process node represent a group of machines running a single recipe. This is where you can apply modifiers and edit your machine count.

## Editing Impact

Changing process-node settings can affect only affect supply, but the effects will propagate through the product flows.

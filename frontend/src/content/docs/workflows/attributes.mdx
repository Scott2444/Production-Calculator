# Attributes (Workflows)

Workflow attributes are computed per process node for both demand and supply views.

<span id="formula-shape" />

## Formula Shape

Node attribute value follows this pattern:

- Add recipe and machine flat contributions
- Add modifier flat contributions
- Apply additive bonuses
- Apply multiplicative bonuses

In compact form:

`amount = (flat_total) * (1 + additive_bonus_total) * multiplicative_bonus_total`

<span id="aggregation" />

## Aggregation

Once computed per node, attribute values are summed across a workflow for project-level analysis.

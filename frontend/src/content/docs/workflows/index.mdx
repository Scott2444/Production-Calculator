# Workflows

Workflows are where project data becomes an executable production plan.

## Workflow Contains

- Targets (what you want to produce)
- Process nodes (recipe and machine execution)
- Product nodes (material flow representation)
- Edges (flow between process and product nodes)
- Preferred recipe constraints
- External product flags

## Two Perspectives

- Demand: the production line required to satisfy your Targets
- Supply: what your current implementation can actually sustain

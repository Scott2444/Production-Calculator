# Modifiers

Modifiers alter recipe and attribute behavior in workflows.

<span id="built-in-modifier-fields" />

## Built-In Modifier Fields

<span id="speed" />

### Speed

- Flat speed bonus
- Percent speed bonus
- Multiplicative speed bonus

<span id="yield" />

### Yield

Yield can modify the ratio of incoming products to outgoing products

- Input percent (yield-related)
- Output percent (yield-related)

<span id="attribute-contributions" />

## Attribute Contributions

Modifiers can also contribute to attributes with flat, percent, and multiplicative terms.

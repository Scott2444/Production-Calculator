# Project Components

Project components define the data model used by workflow solving and chart rendering.

## Core Pieces

- [Products](/docs/projects/components/products)
- [Attributes](/docs/projects/components/attributes)
- [Recipes](/docs/projects/components/recipes)
- [Machines](/docs/projects/components/machines)
- [Modifiers](/docs/projects/components/modifiers)

## Dependency Order

A typical setup order is:

1. Products
2. Attributes
3. Recipes
4. Machines
5. Modifiers

This order minimizes revisiting sections.

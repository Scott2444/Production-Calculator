# Machines

Machines are what process recipes. They are the metric to determine your current deployment.

<span id="key-fields" />

## Key Fields

- Base speed multiplier
- Recipes that this machine can run
- Optional attribute rates

## Best Practices

- Link machines only to recipes they can execute
- Keep machine naming explicit when multiple tiers exist
- Update machine speed assumptions before trusting utilization outputs

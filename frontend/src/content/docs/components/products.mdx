# Products

Products are the item definitions used throughout recipes and workflows.

## Responsibilities

- Represent material identities in a project
- Act as recipe inputs and outputs
- Act as target products in workflows
- Act as external supply candidates in workflows

## Data

- Name
- Description

## Practical Tips

- Keep names unique and descriptive
- Use consistent naming conventions across a project

## Workflow Impact

Deleting a product definition can affect recipe references and workflow charts.
